# AYuan Live2D Working Assets

This folder contains AYuan source exports, Cubism runtime exports, and derived tensor assets.

## Source / Cubism Runtime

- `AYuan/`: see-through generated part PNGs and depth PNGs.
- `AYuan.psd`: generated layered PSD.
- `AYuan_depth.psd`: generated depth PSD.
- `AYuan.cmo3`: Cubism working project.
- `AYuan.moc3`: Cubism runtime model.
- `AYuan.model3.json`: browser-loadable Live2D model entry.
- `AYuan.1024/texture_00.png`: runtime texture atlas.
- `motions/`: current Cubism motion JSON files.

## Derived Helper Assets

- `AYuan_split_layers/`
  - Non-destructive leg/foot helper splits for future Cubism reimport.
  - Generated by `scripts/split-ayuan-live2d-layers.mjs`.
- `AYuan_tensor/`
  - Part-level alpha/depth/control/pin tensors.
  - Generated by `scripts/build-live2d-tensor-assets.mjs`.
- `AYuan_motion_tensors/`
  - `blink`, `thinking`, and `greeting` 16-frame motion tensor sheets.
  - Generated by `scripts/build-live2d-motion-tensors.mjs`.
- `AYuan_static_action_grids/`
  - Full-character 16-grid action reference sheets generated from `assets/live2d/source/AYuan.png`.
  - Generated by `scripts/build-live2d-static-action-grids.mjs`.
  - Use these when checking full-body framing and action rhythm. Use `AYuan_motion_tensors/` when checking tensor displacement/pin data.

## Runtime Intent

The motion tensor files are meant to drive constrained runtime deformation:

- `motion-tensor.png`: per-frame displacement.
- `pin-tensor.png`: seam/contact pinning and role locks.
- `motion-tensor.json`: frame metadata and group transforms.
- `preview-16grid.png`: quick visual check only, not final animation output.

Do not layer duplicate leg/foot overlays in the frontend. Use single-source deformation with pin/seam constraints to avoid ghosting.

## Current Limitations

- The preview sheets use a simple part-composite approximation and can crop at the edge. They are for checking motion direction, not for final visual approval.
- The static action grids preserve full-character framing, but they are driven by whole-character transforms plus simple overlays. They are action references, not a replacement for Cubism ArtMesh/Deformer binding.
- True non-tearing motion still requires Cubism-side ArtMesh/Deformer binding if the final effect needs large body or leg motion.
