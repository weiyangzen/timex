# Live2D Generated Assets

This directory is treated as generated-but-important working data.
Do not delete or overwrite source exports without making a backup first.

## Characters

- `AYuan/`
  - Full generated see-through layer set.
  - Current Cubism runtime export exists: `AYuan.model3.json`, `AYuan.moc3`, `AYuan.1024/texture_00.png`.
  - Derived helper outputs exist:
    - `AYuan_split_layers/`
    - `AYuan_tensor/`
    - `AYuan_motion_tensors/`
- `Weiyang/`
  - Full generated see-through layer set.
  - Tensor-control output exists: `Weiyang_tensor/`.

## Backup Policy

Before changing generated character resources or scripts, create a timestamped backup under:

```text
assets/live2d/backups/YYYYMMDD-HHMMSS/
```

The backup should include:

- `assets/generated/AYuan/`
- `assets/generated/Weiyang/`
- `scripts/build-live2d-tensor-assets.mjs`
- `scripts/build-live2d-motion-tensors.mjs`
- `scripts/split-ayuan-live2d-layers.mjs`
- `SHA256SUMS.txt`

Latest backup at the time of this note:

```text
assets/live2d/backups/20260502-171552/
```

## Generated Outputs

### Base part tensors

Generated by:

```bash
node scripts/build-live2d-tensor-assets.mjs
```

Outputs:

```text
<Character>/<Character>_tensor/tensor-manifest.json
<Character>/<Character>_tensor/control_map.png
<Character>/<Character>_tensor/alpha_map.png
<Character>/<Character>_tensor/depth_map.png
<Character>/<Character>_tensor/pin_map.png
```

These are deformation-control tensors built from the current part PNGs and depth maps.

### Motion tensors

Generated by:

```bash
node scripts/build-live2d-motion-tensors.mjs
```

Default target is `AYuan`. To explicitly target characters:

```bash
LIVE2D_CHARACTERS=AYuan node scripts/build-live2d-motion-tensors.mjs
LIVE2D_CHARACTERS=AYuan,Weiyang node scripts/build-live2d-motion-tensors.mjs
```

Promoted AYuan outputs:

```text
AYuan/AYuan_motion_tensors/motion-tensors.json
AYuan/AYuan_motion_tensors/blink.motion-tensor.json
AYuan/AYuan_motion_tensors/blink.motion-tensor.png
AYuan/AYuan_motion_tensors/blink.pin-tensor.png
AYuan/AYuan_motion_tensors/blink.preview-16grid.png
AYuan/AYuan_motion_tensors/thinking.motion-tensor.json
AYuan/AYuan_motion_tensors/thinking.motion-tensor.png
AYuan/AYuan_motion_tensors/thinking.pin-tensor.png
AYuan/AYuan_motion_tensors/thinking.preview-16grid.png
```

The preview sheets are inspection aids only. The runtime should consume the tensor JSON/PNG and apply deformation with pin/seam constraints.
